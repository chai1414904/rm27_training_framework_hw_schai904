# I²C

## 半双工

**半双工**：只有一条数据线，收发必须分时。

**例：I²C 有 2 条线**，只有**一根数据线 SDA（Serial Data）**，
**同一时刻线上只能有一个电平**，所以收发不能同时进行。

SCL（Serial Clock）是时钟线。

## 为什么 I²C 的线必须开漏

- SDA 的**高电平**都是靠**外部上拉电阻**提供的
- **拉低**只能靠**开漏**模式主动拉到 GND
- 如果把外部上拉电阻去掉，电平将**悬空（非高非低）**
- 两个设备都**没有拉高电平的能力，只能拉低**；而**只要有一个设备拉低，线就是低** —— 这就是「线与」

## 怎么选设备：地址 + ACK

I²C **没有 CS 线**，它靠 **SDA 上的地址字节**来选设备：

- **7 位地址 + 1 位 R/W**，正好一个字节
- **所有从机都收到这 8 位**，但**只有地址匹配的那一个**才回应
- 回应的方式：在**第 9 个时钟**把 **SDA 拉低** —— 这就是 **ACK**
- **每 8 位数据后面都有 1 位 ACK**（ACK 不是"结束传输"）
- **读数据时方向翻转**：改由**从机驱动 SDA、主机接收**
- **整段传输的结束**靠**停止条件**（SCL 为高时，SDA 由低变高）

**谁发 ACK？收数据的那一方**：

| 方向 | 谁在收 | 谁发 ACK |
| --- | --- | --- |
| 写（主机 → 从机）| 从机 | 从机 |
| 读（从机 → 主机）| 主机 | 主机（最后一个字节回 NACK，表示"够了"）|

## 起始 / 停止条件

起始和停止条件**都要求 SCL 为高**，区别在 SDA 的动作：

| | SCL | SDA 的动作 | 相当于 |
| --- | --- | --- | --- |
| **起始** | 高 | 由高变低（**被拉低**）| 起新的一句 |
| **停止** | 高 | 由低变高（**放手**，被上拉电阻恢复）| 说完了 |

**规矩**：SCL 高时 SDA 必须保持；要变只能在 SCL 低时变。

起始/停止之所以能被认出来，正是因为它是"**SCL 为高时 SDA 却变了**"——
正常数据永远不会这样变，所以这个动作可以当**标点符号**用。

## 一位是怎么传的

- **SCL 低**：发送方改 SDA，摆好下一位是 0 还是 1
- **SCL 高**：接收方读 SDA，此时 SDA 必须保持稳定（因为接收方正在采这一位）
- 读完一位后，SCL 再拉低，发送方再改下一位
- 循环传完 8 位，再传 ACK（**ACK 也是一位**，第 9 个时钟）

数据位**最高位先发（MSB first）**：先发 bit7，最后发 bit0。

## 本工程的 I2C3 配置

| 项 | 值 | 它实际改的是 | 为什么这么选 |
| --- | --- | --- | --- |
| Instance | I2C3 | 用哪个 I²C 外设 | IST8310 接在 I2C3 上 |
| ClockSpeed | **400 kHz** | SCL 的速率 | 快速模式（100 k = 标准，400 k = Fast）|
| DutyCycle | 2:1 | 快速模式下 SCL 高/低的时间比例 | 标准值 |
| AddressingMode | 7 位 | 地址宽度 | IST8310 是 7 位地址 **0x0E** |
| OwnAddress1 | 0 | 自己的地址 | **主机不需要地址** ⇒ 填 0 |
| DualAddressMode | 关 | 双地址（从机功能）| 主机用不到 |
| GeneralCallMode | 关 | 广播（所有从机一起听）| 用不到 |
| NoStretchMode | 关 | **允许时钟拉伸** | 允许从机拉低 SCL 说"等一下" |

**引脚**：

| 引脚 | 信号 | 模式 |
| --- | --- | --- |
| **PA8** | SCL | **复用开漏** |
| **PC9** | SDA | **复用开漏** |
| **PG3** | DRDY_IST8310 | 普通 GPIO（传感器 → MCU）|
| **PG6** | RSTN_IST8310 | 普通 GPIO（MCU → 传感器）|

代码里就是这一行（`board/Core/Src/i2c.c` 的 MspInit）：

```c
GPIO_InitStruct.Mode      = GPIO_MODE_AF_OD;   // 复用【开漏】
GPIO_InitStruct.Alternate = GPIO_AF4_I2C3;
```

**开漏不是可选项**：I²C 靠"线与"让多个设备共用一根线，
所以 SDA / SCL 必须**只能拉低、不能推高** —— 这正是 `AF_OD` 的含义。

> **对照 SPI**：SPI 的引脚是**复用推挽（AF_PP）**，因为它**不需要线与**
> （CS 保证同一时刻只有一个从机驱动 MISO）。
